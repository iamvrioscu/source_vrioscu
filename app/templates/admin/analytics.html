How to read these numbers

Page view: one successful page-load event; retries with the same event ID count once. Visit: a browsing session separated by more than 30 minutes of inactivity. Unique visitor: an anonymous browser identifier with a page view in the selected period. Active: activity within the past five minutes; visible pages send a heartbeat every minute.

Periods follow IST calendar days. Visits count by their start time. Totals include only visitors who allow analytics; signed-in users, Do Not Track and Global Privacy Control are excluded. Referrers retain only a host name. No IP addresses, account IDs or full user agents are stored. Records expire after 90 days, with daily cleanup on analytics requests and dashboard access.
