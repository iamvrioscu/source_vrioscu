Download and install

  1. Get the installer from the download page.
  2. Verify its SHA-256 checksum with Get-FileHash -Algorithm SHA256 in PowerShell and compare it with the value on the download page. Step-by-step instructions.
  3. Run the installer.

First run

Every validation follows the same seven steps. See How it works for the full picture.

  1. Configure validation. Choose capture options, and decide whether to use AI Validation Insights for this run.
  2. Enter target endpoints. Add the web endpoints to check. Reusing the same list keeps runs comparable.
  3. Run validation. {{ product.name }} checks each endpoint from this machine and network.
  4. Capture visual evidence. Screenshots and technical details are recorded during the run.
  5. Analyze collected evidence. Evidence is organised per endpoint.
  6. Generate technical report. A PDF is produced from the run.
  7. Review report. Check the report before sharing it.

Run from the machine and network you actually need evidence for. A result from your desk doesn't prove an endpoint works from a remote site.

Reading the report

Reports always use the same sections, in this order:

  1. Cover. Identifies the report and the run.
  2. Test and environment information. What was tested and in what context.
  3. Network environment. Where the test ran from. See Network information.
  4. Validation summary. Results across all endpoints. Start here.
  5. Endpoint technical metrics. Detailed results for each endpoint.
  6. Visual evidence. Screenshots captured during the run.
  7. AI Validation Insights. Only present if you enabled them.

Network information

The desktop application can record details about the machine and network the run executed from, such as hostname, local IP address, gateway, DNS servers, Wi-Fi SSID, signal strength, frequency and channel, and network adapter information.

This information comes from Windows on your device and appears in your report. It isn't collected by this website, and a website can't read it from your browser.

Reports can therefore contain internal network details. Share them the way you'd share any internal technical document.

AI Validation Insights

AI Validation Insights are optional. When enabled for a run, the report includes an AI-generated interpretation of the collected evidence. Validation, capture and reporting all work with them turned off.

If your organisation has rules about AI tools, check them before enabling this option, and treat AI-generated text as a starting point for your own review, not as a conclusion.

Updates and channels

New versions are announced on the download page, with release notes and a checksum for each installer. Releases are published in channels:

  • Public Beta. Early releases available to everyone. The current channel.
  • Stable. General releases, once available.

Some releases may be marked as required when an earlier version is no longer supported.

Website account

A {{ product.name }} website account lets you send product feedback, choose whether to receive product-update emails, and manage or export the data this website holds about you. You can delete your account at any time from your account settings.

Product-update emails are optional and separate from your account. You can turn them on or off without affecting anything else.

Getting help
