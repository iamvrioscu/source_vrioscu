The validation workflow

The desktop workspace lets you configure a test run, deployment context, render wait and capture mode, then enter target URLs or import a CSV.

  1. Validate. Run the supported endpoint checks from your Windows machine.
  2. Capture. Record screenshots and technical metrics during the run.
  3. Analyze. Review endpoint outcomes and the underlying evidence.
  4. Document. Generate and review the Validation & Evidence Report.

Run from the machine and network you actually need evidence for. Results from one location do not establish behavior from another.

Reading the report

The supplied 23-page sample contains:

  1. Cover. Report identity, operator and generation timestamp.
  2. Test details & environment. Configuration, runtime and local network context.
  3. Validation summary. Overall counts, run timing and endpoint outcomes.
  4. Individual endpoint pages. Technical metrics, validation health and visual evidence for each URL.
  5. AI Validation Insights. Evidence-driven assessment, observations, potential issues and recommended action, with an explicit unavailable state when analysis cannot be supplied.

Begin with the summary, then inspect endpoint details. In the sample, two endpoints are reachable and render a page but return HTTP 403, so they are marked for review.

Network context

The sample report includes host device, operating system, browser runtime, local IP, gateway, DNS servers and Wi-Fi information. These are collected by the desktop application from the execution environment.

This website does not inspect your machine or network configuration. Reports may contain internal technical information; consider their contents before sharing.

AI Validation Insights

The new supplied report includes AI Validation Insights for individual endpoint captures. For chatgpt.com, the assessment explains that the endpoint was reachable and rendered content, while HTTP 403 requires review. The report suggests reviewing the URL path, access permissions and authentication policies.

Its analysis model is labelled “VRIOSCU Hybrid Diagnostic Engine” and confidence “High (Deterministic Analysis)”. These pages show historical desktop report output. Live AI analysis is not available on this website.

Page 19 records “AI Validation Insights Unavailable” while retaining deterministic evidence, timings and screenshots. Review all automated interpretations against the underlying evidence; they do not establish a security guarantee.

Releases and channels

The official Windows page and release information page will announce public availability. The release system supports Public Beta and Stable channels, with installer metadata and release notes.

No public installer or update metadata is exposed while the release is marked coming soon.

Your website account

An account lets you send feedback, manage your profile, save a product-update preference, export your personal website data and delete your account. These account features are separate from desktop validation.

Update preferences are opt-in and can be changed in account settings. Automated email delivery is not connected yet; return to the release page for availability announcements.

Getting help

Use the contact form for product, account or report questions. Include the version and what you expected to happen where relevant. Do not include passwords or other secrets.
