The beta includes the product's four capabilities: validate, capture, analyze and document. It's suitable for real work, but you may find rough edges, and behaviour or report layout may change before a stable release.

About installer signing

{% if product.installer_signed %}

The {{ product.version }} installer is digitally signed. You can check the signature in the file's properties in Windows before running it.

{% else %}

The {{ product.version }} installer is not yet digitally signed. Because of that, Windows SmartScreen or your organisation's security software may warn that the publisher is unrecognised, or block the file.

Those warnings are doing their job. Don't turn off SmartScreen, Smart App Control, Microsoft Defender or any other protection to install {{ product.name }}. Instead:

  • Download only from this website.
  • Compare the file's SHA-256 checksum with the one on the download page. If they don't match, delete the file.
  • On a managed work device, follow your organisation's software approval process. Your IT team may need to approve it.
