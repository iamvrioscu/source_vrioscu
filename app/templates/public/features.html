Validate, capture, analyze, document

Four capabilities that make up every {{ product.name }} run. Nothing here depends on the website: it all happens in the Windows application.

Validate

Endpoint reachability and technical health.

  • Enter the endpoints you need to check and run them as one validation.
  • Runs are repeatable, so you can compare before and after a change.
  • Results come from the machine and network you are actually testing.

Capture

High-quality visual evidence with configurable capture options.

  • Screenshots are taken as part of the run, not afterwards.
  • Capture options are configured before you run validation.
  • Technical execution and network details are recorded alongside the images.

Analyze

Structured technical evidence and optional AI Validation Insights.

  • Evidence is organised by endpoint, so results are easy to review.
  • AI Validation Insights can add a written interpretation of the evidence.
  • AI Validation Insights are optional. Validation and reports work without them.

Document

Professional technical reports.

  • A branded PDF generated from the run's recorded results.
  • Consistent structure from cover to evidence.
  • Ready to attach to a change record, sign-off or escalation.

Network environment evidence

When a result depends on where a test ran from, the report needs to say where that was. The desktop application can record details such as:

  • Hostname and local IP address
  • Default gateway and DNS servers
  • Wi-Fi SSID, signal strength, frequency and channel
  • Network adapter and radio information

These come from Windows on the machine running the validation. Browsers don't expose them to websites, and this website doesn't try to collect them.
