Install {{ product.name }}

  1. Download the installer from this page. Don't use copies from other sites or shared drives you can't verify.
  2. Verify the SHA-256 checksum (below). Continue only if it matches exactly.
  3. Run the installer and follow the prompts.
  4. Open {{ product.name }} and follow the first-run guide.

Verify the checksum

In PowerShell, from the folder you downloaded to, run:

Get-FileHash -Algorithm SHA256 .\{{ fname }}

Compare the Hash value with the SHA-256 above. Letter case doesn't matter. If anything differs, delete the file and download it again.
