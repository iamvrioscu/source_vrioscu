Site integration and UAT sign-off

When a new or acquired site joins a network, the business applications people rely on need to work from that site on day one. Run the agreed endpoint list from the site and attach the report to the sign-off.

Post-change verification

After a firewall rule, routing, DNS or proxy change, run the same validation you ran before the change. Two reports from identical runs make the difference easy to see.

Run from
The affected segment, before and after
Report shows
Results and evidence for the same endpoints

Wireless network validation

Prove that a given SSID provides access to the services users need, with the wireless details of the connection recorded in the report's network environment section.

Run from
A laptop connected to the SSID under test
Report shows
SSID, signal, channel and endpoint results
