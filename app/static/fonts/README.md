# Self-hosted typography

Manrope Variable is included as `Manrope-Variable.ttf`, from the official
Google Fonts repository (`google/fonts`, `ofl/manrope`). Its SIL Open Font
License is included as `Manrope-OFL.txt`. No third-party font requests occur.

The shared stylesheet uses font-display: swap, with Segoe UI and system fallbacks.
Technical values use Cascadia Code, SFMono, Consolas or Liberation Mono.
